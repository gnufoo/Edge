# Quick Start Guide

## Prerequisites

- Node.js (v16 or higher)
- npm or yarn
- Unity (2021.3 or higher) for visualization
- Python 3.8+ (for certain AI modules)

## Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/edge.git
cd edge
```

2. Install dependencies:
```bash
npm install
```

3. Configure your environment:
```bash
cp .env.example .env
# Edit .env with your settings
```

4. Run the setup script:
```bash
npm run setup
```

## Basic Usage

1. Start the Edge framework:
```bash
npm run start
```

2. Launch the Unity visualization:
```bash
npm run unity
```

3. Test your installation:
```bash
npm run test
```
